# Brand assets

Source HTML + rendered PNGs. Re-render with headless Chrome:

```
chrome --headless=new --hide-scrollbars --window-size=800,800 --screenshot=thingamalabs-avatar.png avatar.html
chrome --headless=new --hide-scrollbars --window-size=1500,500 --screenshot=thingamalabs-cover.png cover.html
```

- `thingamalabs-avatar.png`: 800x800 profile picture (Ko-fi, GitHub org)
- `thingamalabs-cover.png`: 1500x500 banner (Ko-fi cover)
